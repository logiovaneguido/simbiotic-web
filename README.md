# Simbiotic

Sitio web de **Simbiotic**, consultora de AI & Martech con base en Buenos Aires.

## Estructura

```
simbiotic-web/
├── index.html      # Página principal
├── cases.html      # Casos de éxito
├── style.css       # Estilos globales
└── README.md
```

## Páginas

**`index.html`** — landing principal con secciones:
- Nav fija con scroll effect
- Hero
- Métricas (+22% conversiones, −18% costos, ×2 proyectos)
- Servicios (AI Strategy, Martech & Data Integration, Modelos Predictivos, GEO & Agentes Autónomos)
- Equipo (Guido Logiovane, Francisco de Villalobos, Manuel Massonneau)
- Clientes (Frávega, izzi)
- CTA + Footer

**`cases.html`** — tres casos de éxito:
- Frávega Retail Media
- Frávega Media Mix Optimization
- izzi Churn Prediction

## Stack

HTML5 + CSS3 puro, sin frameworks ni dependencias externas.
Tipografía: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) (Google Fonts).

## Diseño

- Fondo: `#0a0a0a`
- Acento oliva oscuro: `#2a2a1a`
- Texto: `#e4e4e4`
